# Reference Library

Project-owned instructions and facts. Read only the files needed for the current task. The installer seeds missing files in `.agents/reference/` and never overwrites existing files.

| File | Holds | Use when |
| --- | --- | --- |
| [coding-standards.md](coding-standards.md) | Naming, architecture, and exact file headers | Generating or reviewing affected code |
| [planning-template.md](planning-template.md) | One shared plan structure | Planning a complex change |
| [project-context.md](project-context.md) | Org data model, prefixes, integrations, layout, and coverage target | A task relies on org-specific facts |

Authorization and routing come from the shared kit policy. Project references define conventions; domain skills define workflow; local Salesforce skills supply platform mechanics only. Put each project convention here once rather than copying it into instructions.
